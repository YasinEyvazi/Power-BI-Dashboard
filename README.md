< Sales & Profitability Dashboard >
A Power BI portfolio project focused on analyzing sales, profitability, customers, products, and business performance.

Tools:
* Power BI
* Excel
* DAX

This dashboard provides insights into:
* Total sales, profit, and customers
* Sales by category and segment
* Monthly trends in average profit, sales, quantity, and profit margin
* Sales by sub-category
* Profit by state or city
* Profit margin by ship mode
* High-profit products
* Interactive filtering across four years

Project Purpose:
This project was created to demonstrate practical skills in data analysis, data visualization, Power BI, Excel and DAX using a sample dataset.

Project File:
The Power BI `Sales-Dashboard-by-Yasin-Eyvazi.pbix` file is included in this repository.
